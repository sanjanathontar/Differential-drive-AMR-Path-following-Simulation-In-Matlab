# Differential-drive-AMR-Path-following-Simulation-In-Matlab
MATLAB simulation of a differential-drive AMR that follows user-defined waypoints using path and heading control. It calculates X, Y, θ, wheel velocities, RPM, and tracking errors, with real-time visualization of the robot trajectory.

## Features

- Differential-drive kinematics
- User-defined waypoint path
- Path following
- X, Y, θ state calculation
- Wheel velocity and RPM calculation
- Position and heading error monitoring
- Real-time simulation

## MATLAB Code

The main simulation code is available in:

`matlab/amr_path_following.m`
